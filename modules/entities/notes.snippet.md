
## 사람·프로젝트·결정 페이지

```
people/이름.md                 사람 — 지금(덮어씀) + 타임라인(추가만)
projects/<slug>/README.md      프로젝트 — 개요·상태·열린 문제·타임라인
decisions/YYYY-MM-DD 제목.md    확정된 결정 — 무엇을·왜·기각한 대안
meetings/YYYY-MM-DD 제목.md     결정·액션이 있는 회의
```

어디에 쓸지는 `RESOLVER.md` 가 정한다. `/log`·`/scrum pm` 은 RESOLVER 가 있으면 새로 생긴 사실만 이 페이지들에 옮긴다.
