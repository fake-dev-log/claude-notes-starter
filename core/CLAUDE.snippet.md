## 기록 루프

- 노트는 `~/notes` (`daily/`, `queue.md`, `lessons/`). **사람이 손으로 쓰지 않는다 — Claude 가 쓴다.** 구조는 `~/notes/README.md`.
- 작업 한 덩어리가 끝나면 `/log`. 새 세션은 `/next` 또는 오늘 daily 를 먼저 읽고 시작한다.
- 한 세션에 작업 두 덩어리를 넘기지 않는다. `/log` 뒤에 세션을 끊는다.
- 워크스페이스 메모리(`~/.claude/projects/<slug>/memory/`)는 다음 세션의 Claude 용, daily 는 사람용. 같은 사실이라도 대상이 다르니 한쪽만 쓰고 끝내지 않는다.
